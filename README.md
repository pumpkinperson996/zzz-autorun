# 无人值守自动运行指南

本指南面向**不会写代码的普通用户**，帮助你在 Windows 10 上配置一套全自动运行一条龙的系统。

配置完成后，电脑可以每天自动重启，重启后自动登录，自动启动一条龙并点击开始，遇到游戏异常自动关闭并重启，全程不需要人工干预。

## 1. 整体流程是什么

```
每天凌晨 4 点 → 电脑自动重启
       ↓
  Windows 自动登录
       ↓
  自动启动监控脚本
       ↓
  脚本启动 OneDragon-Launcher.exe
       ↓
  等待一条龙界面加载完成
       ↓
  自动点击「启动一条龙 🚀」按钮
       ↓
  ┌──────────────────────────────────────────────────────────┐
  │  持续监控（三条并行检测线）                                │
  │                                                          │
  │  ① 每 0.5 秒  扫描屏幕是否出现游戏异常登录弹窗           │
  │  ② 每 1 分钟  读取一条龙日志，检测是否出现               │
  │               「指令[ 一条龙 ] 执行失败」                 │
  │  ③ 每 10 分钟 检查两个进程是否都还活着（进程守卫）         │
  └──────────────────────────────────────────────────────────┘
       ↓ 触发后
  关闭游戏本体 + 关闭一条龙
       ↓
  ① 触发：等待 1 小时再重启
     （账号被顶号，弹窗会留在屏幕，等待情况恢复）
  ②③ 触发：立即重启
     （运行出错或进程意外消失，直接重启即可恢复）
       ↓
  重新启动一条龙（游戏由一条龙自动拉起）
       ↓
  回到「持续监控」状态
```

**防死循环机制**：检测到异常弹窗后，90 分钟内暂停弹窗扫描，避免弹窗残留导致一条龙刚重启就又被关掉。

**防睡眠机制**：脚本启动时自动阻止电脑进入睡眠，防止系统自动休眠导致监控中断。

**进程守卫说明**：启动一条龙后有 3 分钟宽限期不触发守卫，避免游戏还没被拉起来就误判为异常。守卫会处理以下情况：

| 情况 | 处理方式 |
|------|---------|
| 按钮没点到，一条龙开着但游戏没跑 | 关闭两者，重新启动 |
| 一条龙意外崩溃（无日志记录） | 检测到进程消失，立即重启 |
| 游戏崩溃，一条龙还在 | 关闭两者，重新启动 |
| 两个进程同时消失 | 立即重启 |

> ⚠️ **监控脚本自身崩溃的情况**：如果 AutoHotkey 脚本本身意外退出，上面所有检测都会停止。建议在任务计划程序中额外添加一个每 15 分钟触发的任务，检查脚本是否在运行，不在则重新启动。具体配置见第 6B 节，触发器改为「按计划 → 每 15 分钟」即可。

## 3. 安装 AutoHotkey

1. 打开浏览器，访问 [https://www.autohotkey.com/](https://www.autohotkey.com/)
2. 点击 **Download** → 选择 **AutoHotkey v1.1**（注意是 v1，不是 v2）
3. 下载后双击安装，全程点「Next」即可
4. 安装完成后，`.ahk` 文件会显示绿色图标

> **如何验证安装成功**：右键桌面空白处，菜单里能看到「New → AutoHotkey Script」说明安装成功。

## 4. 准备弹窗截图

脚本通过识别屏幕上的图片来检测游戏异常弹窗。你需要提前截取一张弹窗的特征图片，保存到指定位置。

**弹窗长这样**（游戏内提示）：
> 您的账号在其他地方登录，请检查是否存在账号泄露风险，是否要重新登录游戏？

### 截图步骤

1. 等游戏出现这个弹窗时（或者找一张截图）
2. 按 `Win + Shift + S` 打开截图工具
3. 框选弹窗中**最有特征的一小块区域**（比如弹窗标题或提示文字部分），不要截整个屏幕
4. 截图会自动复制到剪贴板
5. 打开「画图」程序（搜索栏输入「画图」），按 `Ctrl+V` 粘贴
6. 另存为，格式选 **PNG**，保存路径填：

```
C:\ZZZ-OD\popup_banner.png
```

> **注意**：文件名必须完全一致，包括大小写。

## 5. 配置 Windows 自动登录

脚本需要在有桌面的情况下运行（鼠标点击、屏幕识别都需要已登录状态）。如果电脑重启后需要手动输密码，就没法全自动了。

### 设置自动登录

1. 按 `Win + R`，输入 `netplwiz`，回车
2. 在用户列表中点击你的账户
3. **取消勾选**「要使用本计算机，用户必须输入用户名和密码」
4. 点「应用」，会弹出密码确认窗口
5. 输入你的 Windows 登录密码（两次），点「确定」
6. 重启电脑验证：重启后应直接进入桌面，不需要输密码

> ⚠️ **安全提示**：自动登录意味着任何人拿到电脑都能直接进入系统。如果电脑放在安全的私人场所，这通常可以接受。

## 6. 在任务计划程序中添加任务

任务计划程序是 Windows 内置的定时任务工具，我们用它来触发两件事：每天定时重启电脑，以及登录后自动启动脚本。

### 打开任务计划程序

按 `Win + S`，搜索「任务计划程序」，打开它。

---

### 6A. 每天定时重启电脑

1. 右侧点「**创建基本任务**」
2. **名称**填：`Daily Reboot 4AM`，点下一步
3. **触发器**选「每天」，点下一步
4. **开始时间**填：`04:00:00`，点下一步
5. **操作**选「启动程序」，点下一步
6. **程序或脚本**填：
   ```
   C:\Windows\System32\shutdown.exe
   ```
7. **添加参数**填：
   ```
   /r /t 0 /f
   ```
   （含义：`/r` 重启，`/t 0` 立刻执行，`/f` 强制关闭程序）
8. 点下一步 → 完成

**验证**：右键刚创建的任务 → 「运行」，电脑应立即重启。（可选，确认没问题再做）

---

### 6B. 登录后自动启动监控脚本

1. 右侧点「**创建任务**」（不是「创建基本任务」）

#### 「常规」选项卡

- **名称**填：`OneDragon AutoRun`
- 勾选「**使用最高权限运行**」
- 「配置」选 `Windows 10`

#### 「触发器」选项卡

1. 点「新建」
2. **开始任务**选「**登录时**」
3. **特定用户**选你自己的账户
4. 点「确定」

#### 「操作」选项卡

1. 点「新建」
2. **操作**选「启动程序」
3. **程序或脚本**填（根据你电脑的 AutoHotkey 安装路径）：
   ```
   C:\Program Files\AutoHotkey\v1.1\AutoHotkey.exe
   ```
   > 如果找不到，打开文件资源管理器，进 `C:\Program Files\AutoHotkey\`，找到 `AutoHotkey.exe` 或类似文件，复制路径。
4. **添加参数**填：
   ```
   "C:\ZZZ-OD\OneDragon_FINAL_Restart_90min.ahk"
   ```
5. **起始于**填：
   ```
   C:\ZZZ-OD
   ```
6. 点「确定」

#### 「设置」选项卡

- 找到「如果此任务已经运行，以下规则适用」
- 改为「**不启动新实例**」

最后点「确定」保存。

**验证**：注销再重新登录，观察脚本是否自动启动（任务栏右下角托盘区域会有 AutoHotkey 图标）。

## 7. 脚本参数说明

脚本文件位于：

```
C:\ZZZ-OD\OneDragon_FINAL_Restart_90min.ahk
```

用记事本打开可以修改参数。以下是你最可能需要调整的几个：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `btnX` | `1470` | 「启动一条龙」按钮的横坐标（Client 坐标） |
| `btnY` | `1055` | 「启动一条龙」按钮的纵坐标（Client 坐标） |
| `postLaunchSleep` | `1500` | 一条龙启动后等多久再点按钮（毫秒） |
| `checkInterval` | `500` | 弹窗扫描间隔（毫秒），500 = 每 0.5 秒 |
| `imgTolerance` | `90` | 弹窗图片识别容错度，90 已经很宽松 |
| `restartDelay` | `3600000` | 检测到异常后等多久重启（毫秒），默认 1 小时 |
| `cooldownMs` | `5400000` | 检测到弹窗后的冷却时间（毫秒），默认 90 分钟 |
| `failCheckInterval` | `300000` | 读取一条龙日志的间隔（毫秒），默认 5 分钟 |

---

## 8. 如何调整参数

### 按钮坐标失效时（一条龙更新后按钮位置可能变化）

1. 打开 AutoHotkey 自带的 **Window Spy**：
   - 在 AutoHotkey 安装目录找到 `WindowSpy.ahk`，双击运行
   - 或者右键任何 `.ahk` 文件 → 「Run with」→ 找到 WindowSpy
2. 启动一条龙，等界面完全加载
3. 把鼠标移到「启动一条龙 🚀」按钮**正中心**
4. 查看 Window Spy 窗口里 `Client` 那行显示的两个数字（例如 `1470, 1055`）
5. 用记事本打开脚本，把 `btnX` 和 `btnY` 改成新的数字，保存

> ⚠️ 必须用 `Client` 坐标，不要用 `Screen` 坐标。

### 修改等待时间

用记事本打开脚本，找到对应的参数，修改数字，保存。

**常用换算**：
```
60000    = 1 分钟
300000   = 5 分钟
600000   = 10 分钟
3600000  = 1 小时
5400000  = 90 分钟
7200000  = 2 小时
```

## 9. 如何查看运行日志

脚本运行时会写两个日志文件：

### 脚本自身日志（推荐优先看这个）

```
C:\ZZZ-OD\closedloop.log
```

用记事本打开。正常运行时应该能看到：

```

2026-05-16 06:01:05  START: clicked start button at screen x=1580 y=1120
```

这个日志记录一条龙运行过程中的详细信息，每天自动归档，保留最近 3 天。

## 10. 常见问题排查

### 脚本没有自动启动

- 检查任务计划程序里 `OneDragon AutoRun` 任务是否存在
- 右键任务 → 「运行」，看是否手动触发成功
- 检查「常规」选项卡是否勾选了「使用最高权限运行」
- 确认 AutoHotkey 路径填写正确

### 一条龙启动了但没有点击按钮

可能原因：
1. **等待时间不够**：把 `postLaunchSleep` 从 `1500` 改成 `4000`
2. **按钮坐标偏了**：用 Window Spy 重新测量坐标，更新 `btnX` 和 `btnY`
3. **一条龙版本更新后按钮位置变化**：同上，重新测坐标

### 游戏异常弹窗没有被检测到

可能原因：
1. **截图不对**：重新截取 `popup_banner.png`，选取特征更明显的区域
2. **容错度不够**：把 `imgTolerance` 从 `90` 改成 `80`（降低容错，更严格匹配）或 `95`（更宽松）
3. **截图文件路径不对**：确认文件保存在 `C:\ZZZ-OD\popup_banner.png`

### 运行失败检测没有触发

- 确认一条龙日志文件存在：`C:\ZZZ-OD\.log\log.txt`
- 检查 `closedloop.log` 里是否有 `FAILDETECT` 字样
- 如果看到 `ERROR: launcher not found` 或 `ERROR: popupImg not found`，说明路径配置有问题

### 任务计划程序里任务一直显示「正在运行」

这是正常现象，脚本会持续在后台运行监控游戏状态。

### 电脑重启后没有自动登录

- 重新检查第 5 步「配置 Windows 自动登录」
- 确认 `netplwiz` 里已取消勾选密码要求

## 11. 测试方法

在正式无人值守运行之前，建议先手动测试各个环节。

### 测试一：手动运行脚本

1. 确保一条龙已关闭
2. 双击 `OneDragon_FINAL_Restart_90min.ahk`
3. 观察：一条龙是否自动启动？按钮是否被点击？
4. 查看 `C:\ZZZ-OD\closedloop.log` 确认日志正常

### 测试二：测试运行失败检测

> 需要先把脚本里 `failCheckInterval` 临时改为 `10000`（10 秒），测试完改回 `300000`。

1. 让脚本运行，等 `closedloop.log` 出现 `MONITOR: armed`
2. 打开 PowerShell（搜索栏输入 `powershell`），粘贴以下命令并回车：

```powershell
$fs = [System.IO.FileStream]::new("C:\ZZZ-OD\.log\log.txt", [System.IO.FileMode]::Append, [System.IO.FileAccess]::Write, [System.IO.FileShare]::ReadWrite)
$sw = [System.IO.StreamWriter]::new($fs, (New-Object System.Text.UTF8Encoding $false))
$sw.WriteLine("指令[ 一条龙 ] 执行失败 返回状态 失败")
$sw.WriteLine("暂停运行")
$sw.WriteLine("松开所有按键")
$sw.WriteLine("停止运行")
$sw.Close()
$fs.Close()
```

3. 等约 10 秒，查看 `closedloop.log`
4. 应看到 `FAILDETECT` 相关日志，一条龙被关闭并重启

### 测试三：测试定时重启任务

在任务计划程序里右键 `Daily Reboot 4AM` → 「运行」，电脑应立即重启，重启后自动登录并自动运行脚本。
